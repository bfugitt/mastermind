Code Breaker

A secret code of colors is hiding. Use the clues to crack it!

How to play

  1. Find the secret code. The computer hides a row of colors. You can’t see it, but you can figure it out.
  2. Make a guess. Tap colors to fill your row, then press Check.
  3. Read the clues. Little dots appear beside your guess:
    right color, right spot right color, wrong spot
    The dots don’t say which peg earned them. That’s the puzzle!
  4. Think, then guess again. Use every clue to rule colors in or out. Crack the code before you run out of guesses.

Tip: tap the ✕ on a color to cross it off when you know it’s not in the code.
